# Chronicle-Customizer

**An in-game customisation mod for the Chronicle Windows PC port of Dark Cloud 1.**

Chronicle-Customizer aims to provide a ready-to-play customisation experience using the Chronicle Mod Framework, with a preconfigured in-game Mod Manager and additional gameplay customisation options.

The goal is to give players greater control over different aspects of Dark Cloud through an accessible interface, without requiring them to manually edit game values.

---

## Current Development Status

**Implemented: Custom Gilda**

The first feature allows players to enter a custom numerical amount of Gilda through the in-game Mod Manager.

- Enter a custom amount using your keyboard.
- Add Gilda to your existing wallet balance.
- Access the feature through R1 Actions.
- View instructions and important information in the Details section.

**Important:** Custom Gilda adds to your existing balance rather than replacing it.

The maximum wallet balance is **65,535 Gilda**. Ensure your existing balance plus the entered amount does not exceed this limit.

## Download and Installation

**Windows ready-to-play package — Coming soon.**

The intended release format is a preconfigured Windows package containing:

- A compatible Chronicle Windows executable.
- The preconfigured Mod Manager.
- Chronicle-Customizer already installed.
- Required runtime files.
- Installation instructions.

The aim is to allow players to download, extract and launch the package without having to compile Chronicle or manually configure the mod.

## Project Information

Chronicle-Customizer builds upon the existing Chronicle Mod Framework.

The current implementation uses Lua for gameplay actions and C++ modifications for additional menu functionality and numerical keyboard input.

For the full project introduction, development information, demonstrations, Mod Manager explanations and community discussion, see the project's Reddit post.

**Community suggestions and requests for additional customisation features are also welcomed through the Reddit post.**
