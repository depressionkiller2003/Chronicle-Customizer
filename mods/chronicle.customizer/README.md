# Chronicle Customizer package

Mod ID: `chronicle.customizer`. Version: `1.0.0`.

Provides Custom Gilda and HP/DEF for all six characters. The matching native host
adds ordered character folders, story locks, numeric input and weapon-tree UI.
This Lua package alone is not sufficient for an unmodified Chronicle executable.

Copy this directory beside a compatible executable under
`mods/chronicle.customizer`, or into the selected save root's `mods` directory.
Enable it in **Options → Mods → Mod Manager** and restart. Avoid duplicate copies.

Permissions: `economy.write`, `game.write`. Capability: `menu.actions.v1`.
No game assets or saves are included.

See [usage](../../docs/USAGE.md), [building](../../docs/BUILDING.md), and
[save safety](../../docs/SAVE-SAFETY.md).
