CHRONICLE CUSTOMIZER v0.2.0 - WINDOWS x64

1. Extract the entire ZIP into a NEW folder. Do not run inside the ZIP.
2. Open darkcloud.exe (or Launch-Chronicle-Customizer.bat).
3. Supply your own supported Dark Cloud game data when the first-run setup asks.
   No disc image or extracted game data is included in this download.
4. Open Options > Mods > Mod Manager. Enable Chronicle Customizer if it is not
   already enabled, then restart the game. First-time users must do this step.
5. Load a save. In the Mod Manager, select Chronicle Customizer > R1 Actions.

WHAT IS NEW
- Custom Gilda and HP/DEF for all six characters.
- Ordered folders: Toan, Xiao, Goro, Ruby, Ungaga, Osmond; HP then DEF inside.
- Characters who have not joined are Locked and cannot be edited.
- In the NORMAL Weapon menu, select a weapon and open its action list.
  The light-orange View Build-up Tree is below all available normal actions,
  including Status Break. Up/Down browses; Left/Right pages; Circle/Back returns.
- Normal Build-Up choices now display their weapon names instead of ???.
  The normal requirements still apply. Tree preview does not change weapons.

STAT INPUT
- HP: 1-32767. Sets maximum HP; increasing it does not heal.
- DEF: 0-32767. Sets base defense.
- Gilda: enter an amount to ADD. Keep the resulting wallet at or below 65535.
- Type digits, press Enter, close menus and resume gameplay briefly to apply.
- Backspace edits numeric entry; Escape cancels it.

SAVES AND UPGRADING
- Back up your existing saves before experimenting. Use a spare test slot.
- Extract this release separately from older downloads. Do not copy old backup
  executables or duplicate retired mod folders into this new installation.
- The normal game save location is reused unless you explicitly choose another
  save root. This package includes no save folder, config or personal profile.
- Loading a save or viewing the tree does not require saving. Stat and Gilda
  changes can persist through saving or normal gameplay autosaves.
- Mod identity remains chronicle.customizer version 1.0.0 for compatible saves.
  v0.2.0 is the application release version, not a change to that saved mod ID.
- Saves requiring the old liam.custom-stats ID are not automatically migrated.
- Do not delete old backups or rewrite save checksums to try to fix compatibility.

VALIDATION
Windows Release build and targeted Lua/C++ checks passed. Isolated scripted
gameplay verified tree opening, branches, terminal weapons, controller Back and
named upgrade choices. Other character routes, mouse controls, story recruitment
and broader save/reload scenarios still need manual testing. This is a developing
Customizer, not a claim of exhaustive game coverage.
